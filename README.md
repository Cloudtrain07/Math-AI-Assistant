# 数学学习 AI 助手（Math_AI_Assistant / MAA）

面向个人学习和可信小范围使用的数学聊天助手：用互动模式逐步引导，用解答模式展示完整步骤，并支持题目图片输入。

当前项目文档版本：**v2.0.0（2026-10-07）**。更新记录见 [CHANGELOG.md](CHANGELOG.md)，当前状态与后续候选事项见 [PLAN.md](PLAN.md)。

## 项目介绍

当前架构是 **Vue + TypeScript + Vite 前端、FastAPI 后端、独立 Python 聊天服务**。回答通过 SSE 流式传输，公式由 KaTeX 渲染；账号、聊天历史和每日用量仍使用本地 JSON 文件保存，没有接入数据库。

现有功能：

- 按小学、初中、高中、大学学段组织讲解，支持互动／解答模式及解答风格选择。
- 普通发送与继续生成共用核心聊天流程；可以停止接收、新建对话，并在登录或刷新后恢复已保存的历史。
- 支持配置多个 OpenAI 兼容服务商，切换模型；思考开关与强度选项根据当前模型的能力规则显示。
- 显示模型实际返回的思考内容与用量。思考内容可折叠，在当前页面显示，不写入聊天历史，也不作为历史回传模型；模型不返回这部分内容时不会凭空生成。
- 上传或粘贴图片后，可先自由裁剪、90° 旋转、微调角度、缩放和重置，再确认发送。
- 流式显示时暂存未闭合公式，已完成公式保持稳定；保留段落空行和有序列表的起始编号。主动向上阅读时不强制跟随底部，可点击“回到底部”恢复跟随。
- 长上下文摘要压缩、按账号保存历史、每日用量阈值检查、日志、每日备份及本机管理员面板。

**当前没有**习题库／组卷、自动符号验算、图片转写兜底或内置公网隧道。旧 Gradio 界面已经退役；历史版本中提到的这些功能不是当前使用说明。模型回答和“深度思考”都不保证数学结论正确，重要步骤仍需自行核对。

## 安装与启动（Windows）

以下命令在 **VS Code 的 PowerShell 终端**运行，起始目录为项目根目录，即包含 `api.py` 的文件夹。

### 1. 准备环境与后端依赖

需要 Python、Node.js（含 npm）和可用的大模型服务商密钥。本机核对环境为 Python 3.13、Node.js 24；本次文档更新没有验证其他版本或其他操作系统。

以下使用 Python 3.13；如果没有 `py` 启动器，可以用已确认版本的 `python` 替代第一条命令。

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

直接使用虚拟环境解释器，无需执行激活脚本。已有可用的 `.venv` 时，不必重新创建。

### 2. 准备配置

仅在没有 `.env` 时复制模板，避免覆盖已有密钥：

```powershell
if (-not (Test-Path .env)) {
    Copy-Item .env.example .env
}
```

在 VS Code 打开 `.env`，把准备使用的服务商密钥占位文字替换为真实值。至少一个已配置服务商需要有可用密钥，才能进行真实模型对话；不使用的密钥项应留空，不要保留模板中的 `sk-你的…密钥` 占位文字。密钥只放在本机配置中，不放进文档或提交到 Git。

服务商配置是可选的，具体规则见下文。没有自定义配置时使用内置 DeepSeek／OpenAI 清单；如果只想按 DeepSeek 模板起步，可以复制：

```powershell
if (-not (Test-Path config/providers.json)) {
    Copy-Item config/providers.example.json config/providers.json
}
```

**复制后的有效清单会替换内置清单，不会自动追加 OpenAI。** 已经有 `providers.json` 时直接编辑，不要覆盖。

### 3. 安装并构建前端

```powershell
Set-Location frontend
npm ci
npm run build
Set-Location ..
```

构建后应有 `frontend/dist/index.html`。后端负责提供这份页面，不需要另启 Vite 才能正常使用。修改前端源码后，需要重新构建才能让正式启动页面使用新内容。

### 4. 启动

仅在本机使用：

```powershell
.\.venv\Scripts\python.exe api.py
```

默认访问 [http://127.0.0.1:8000](http://127.0.0.1:8000)，自动打开浏览器可通过 `AUTO_OPEN_BROWSER=false` 或启动参数 `--no-browser` 关闭。

希望在可信局域网内使用时，可以双击 `启动数学助手.bat`，或运行：

```powershell
.\.venv\Scripts\python.exe api.py --host 0.0.0.0 --port 8000
```

脚本绑定 `0.0.0.0:8000`，优先使用项目虚拟环境，找不到时才使用系统 Python；它检查 `.env` 和前端构建产物，但**不会自动安装依赖或构建前端**。

同一局域网的设备访问 `http://<电脑实际局域网IP>:8000`，也可查看启动窗口打印的局域网地址。不要在浏览器里输入 `0.0.0.0`；电脑需持续运行服务，防火墙也需允许相应连接。不建议为本项目直接开放公网端口。

### 5. 获取账号并登录

正常首次启动会创建 `data/accounts.json`，默认账号为 `user1`～`user5`，密码随机。用 VS Code 在本机打开该文件，取得自己的用户名和密码；正式账号密码不会在启动窗口打印。

已有有效账号清单时不重新生成。账号条目包含 `username`、`password`、`display_name`、`level`、`enabled`；需要增删或编辑时，先停止服务，保留合法 JSON 结构，修改后重启。本机管理员面板也可以重置密码。不要把整个账号文件发给其他人。

停止服务时，在启动终端按 Ctrl+C，等待退出后再关闭窗口。

## 使用方法

1. 登录后选择模式、学段、服务商和模型；需要时调整解答风格、思考开关和强度。
2. 输入题目后点击发送，或按 Enter；Shift+Enter 换行，中文输入法确认候选文字不会触发发送。
3. 图片可以通过文件选择或粘贴进入编辑弹窗。确认编辑后只是本地待发送预览，**点击发送才上传到后端**。只发图片不打字时，程序会附上“请解答图中题目”的请求。
4. 选择的实际模型必须支持图片输入。当前没有 OCR 转写兜底：文本服务商会拒绝带图请求并保留待发送图片，需要换用支持识图的配置或自行输入题目文字。图片读取失败时会给出提示并降级为纯文本发送。
5. 同一题的后续普通追问可复用服务端暂存的图片；移除图片、清空对话或被判断为新题时会停止复用。“继续生成”不等同于重新上传图片。
6. 回答截断后可以点击“继续生成”。点击停止会中止接收，未完成的回答不会作为完成历史写入；API 异常可能保留已生成的部分答案，与主动停止不是同一种结果。
7. “新对话”需要二次确认，会清空本账号历史和当前图片状态；不是创建一个可以切回的独立会话。清空前请保存需要保留的内容。

支持 JPG／JPEG、PNG、WEBP、BMP、GIF；原图和上传内容受 10 MiB 限制，后端还校验实际图片内容与像素数量。发送给模型前会进行 JPEG 编码、长边不超过 2048 像素的预处理，因此不是原文件无损直传，也不保留 GIF 动画。

历史保存的是文本，**刷新／恢复历史不会恢复原图或图片缩略图**；当前页面里的思考内容也不会随历史恢复。

## 配置

### 环境变量

`.env` 由启动流程加载；已有系统环境变量优先，不会被文件覆盖。修改后重启生效。下表是当前代码的缺省值，不是服务商接口可用性的承诺。

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `DEEPSEEK_API_KEY` | 空 | DeepSeek 密钥 |
| `OPENAI_API_KEY` | 空 | OpenAI 密钥 |
| `DEEPSEEK_BASE_URL` | `https://api.deepseek.com` | 内置 DeepSeek 清单使用的接口地址 |
| `DEEPSEEK_MODEL` | `deepseek-v4-flash` | 内置 DeepSeek 清单的默认模型；自定义清单以自身配置为准 |
| `DEEPSEEK_THINKING` | `false` | 默认思考开关，不保证答案正确性 |
| `DEEPSEEK_REASONING_EFFORT` | `high` | 环境默认值接受 `low/high/max`；页面可选档位由当前模型规则决定，不是所有模型都有强度选项 |
| `MAX_HISTORY_MESSAGES` | `20` | 发给模型的近期历史窗口，单位是消息条数，不是对话轮数 |
| `MAX_OUTPUT_TOKENS` | `30000` | 请求中的输出上限；推理计入方式和接口接受范围取决于所选模型 |
| `MAX_WAIT_SECONDS` | `600` | 请求等待保护（秒，包含思考阶段） |
| `MAX_MESSAGE_LEN` | `2000` | 单条输入字符限制，超长直接拒绝 |
| `DAILY_TOKEN_LIMIT` | `1000000` | 每账号每日用量检查阈值 |
| `GLOBAL_DAILY_TOKEN_LIMIT` | `3000000` | 所有账号合计的每日用量检查阈值 |
| `ACCOUNT_COUNT` | `5` | 首次创建账号清单的数量；已有清单不随该值扩增 |
| `AUTO_OPEN_BROWSER` | `true` | 是否自动打开页面；隔离启动默认不打开 |

近期消息不足窗口大小时不会因此生成摘要；超过窗口后，把较早内容增量压缩为摘要，与近期原文一起发送。摘要不是完整原文，可能丢失细节；生成摘要可能额外调用模型，失败时使用保守截断摘要。这个窗口**不会删除已保存的完整文本历史**，也不是精确的 token 长度限制。

用量主要依据接口返回的 token 信息，并提供会话显示和每日累计。发送前检查每日阈值，完成后累计；一个请求可能越过阈值，并发请求也可能同时通过检查。因此这不是严格费用上限，不能替代服务商侧的账单、额度和密钥管理。

### 服务商清单

本机文件为 `config/providers.json`，安全模板为 [config/providers.example.json](config/providers.example.json)。本机文件已被 Git 忽略。

- 有有效自定义条目时，使用该清单替换内置清单；文件缺失、无法解析或没有有效条目时回退内置 DeepSeek／OpenAI。
- 界面只提供已配置对应密钥的服务商。复制 DeepSeek 单服务商模板后，如需其他服务商，应在同一 JSON 数组里添加条目。
- 配置字段为 `id`、`name`、`base_url`、`api_key_env`、`models`、`default_model`、`thinking_param` 和可选的 `supports_vision`。
- `api_key_env` 写环境变量名称，而不是直接写密钥；`default_model` 应在 `models` 清单中。
- `thinking_param` 控制思考参数风格；设为 `none` 时不发送思考参数。具体强度档位还受当前模型匹配规则影响，不能假定所有 OpenAI 兼容服务都接受同一参数。
- `supports_vision` 缺省为 `false`。模板没有开启识图；只有所选接口和模型实际支持图片时，才应声明为 `true`。

模板及内置清单中的模型名是项目配置示例，**本次没有验证它们在真实服务商接口上是否可用**。请根据自己的服务商文档和权限核对模型名、接口地址、图片能力及思考参数，不要只改标记来“开启”一个模型原本不具备的能力。

## 数据、备份与使用限制

### 数据位置

| 路径 | 内容 |
| --- | --- |
| `data/accounts.json` | 账号资料及明文密码 |
| `data/history/<账号>.json` | 按账号保存的文本历史 |
| `data/usage_daily.json` | 每日用量与相关计数 |
| `data/access.log` | 访问及账号事件，保留最近 1000 行 |
| `data/chat.log`、`data/error.log` | 提问／回复及错误信息，分别保留最近 2000 行 |
| `data/访问地址.txt` | 本次启动的访问信息，不包含账号密码 |
| `data/temp_images/` | 按账号存放的临时图片 |
| `data/backups/` | 每日数据备份 ZIP |

聊天历史与每日用量按账号隔离；日志是共享文件，并非每账号一份。不要在服务运行时直接编辑历史或用量文件。

### 备份规则

启动时尝试创建当天的 `math-backup-YYYY-MM-DD.zip`；当天已有同名备份时不覆盖。启动备份成功或当天已存在时，清理超出最近 14 份的、符合备份命名规则的旧文件；启动备份写盘失败时保留旧备份。

持续运行时，后台每小时检查日期变化，跨天后执行备份与清理。因此它不是实时备份，也不是保证零点立即执行。文件删除失败可能留下超过 14 份的备份，请留意磁盘状态。

ZIP 包含数据目录中的账号、历史、用量、日志和其他文件，仅排除 `backups` 自身；**备份也包含明文密码及可能的题目图片**。需要恢复时，先停服务，再由你选择备份和恢复内容，避免覆盖现有数据；当前没有一键恢复界面。

### 安全与部署边界

- `.env`、`config/providers.json` 和 `data/` 被 Git 忽略，但忽略规则不等于加密、脱敏，也不能撤回已经泄露的文件。
- 账号密码明文保存；本机管理员重置密码不会立即让已有登录会话失效。会话保存在进程内存中，当前有效期为 7 天，重启服务后需要重新登录。
- 管理接口限制本机访问，但这不代表已经完成公网部署安全验证。局域网 HTTP 访问没有传输加密，请只在可信网络使用。
- 会话、锁和图片注册信息依赖单进程内存。按默认方式运行，不要直接启用多 worker 或把开发自动重载当成正式部署。
- 模型请求会把相关题目文字、近期历史、摘要和必要图片发送给所选服务商；本地日志也可能保存问题、回复、IP 和错误信息。使用前应确认这些内容可以交给对应服务商。
- 当前不是严格成本控制或多人公网部署系统；真实模型表现、手机实际体验和公网部署不因测试通过而得到保证。

### 代码入口

```text
api.py                    # HTTP / SSE、会话与图片适配、管理员接口和启动任务

core/storage.py           # 文本历史持久化

core/logger.py            # 日志写入

core/message_builder.py   # 模型消息组装
```

### 前后端测试

后端开发依赖另行安装：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
```

在 VS Code 选择 `.venv` 的 Python 解释器，以 pytest 配置测试发现目录 `tests`，然后在“测试”面板运行相关测试或全部测试。终端等价命令：

```powershell
.\.venv\Scripts\python.exe -m pytest tests -q
Set-Location frontend
npm test
npm run build
Set-Location ..
```

前端构建包含 TypeScript 类型检查。测试范围包括聊天流程、用量与持久化、账号隔离、API 边界、图片、备份和流式解析等；测试数量会变化，不将固定数量作为功能说明。提交前用 VS Code 源代码管理检查差异，确认没有密钥、正式数据或临时验收文件混入。

### 不调用真实模型的页面联调

```powershell
.\.venv\Scripts\python.exe api.py --isolated --fake --no-browser
```

手动打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)，用控制台打印的**隔离测试账号**登录。隔离配置与文件数据落在打印出的临时目录，假客户端替换可选服务商客户端，不调用真实模型；测试数据不是正式记录。

**不要单独使用 `--fake` 代替隔离：它只替换模型客户端，仍可能读取和写入正式账号与数据。** 隔离模式不会清空进程已有的系统环境变量，假客户端的能力也按当前服务商配置声明决定；它不能验证真实模型的识图或解题能力。临时目录不保证在退出时自动删除，不应作为长期存储。

修改界面时，可在第二个终端启动 Vite：

```powershell
Set-Location frontend
npm run dev
```

访问 Vite 输出的地址（通常为 `http://localhost:5173`），`/api` 请求会代理到本机 8000 端口；第一个终端中的后端必须保持运行。其他端口需同步开发代理配置，不属于首次安装步骤。

### 常见问题

- **提示缺少前端产物**：在 `frontend` 执行 `npm ci` 和 `npm run build`，回到根目录再启动。
- **服务商列表为空或发送提示密钥不可用**：检查当前有效清单、对应 `api_key_env` 和 `.env`，修改后重启；有占位文字不等于密钥有效。
- **带图请求被拒绝**：检查当前模型是否实际支持识图及 `supports_vision` 配置；没有自动转写兜底。
- **端口被占用**：先确认并停止旧服务，或给后端指定另一个 `--port`；不要随意终止不属于本项目的进程。
- **Python 测试临时目录拒绝访问**：可给 pytest 指定一个新的、可写且专用于测试的 `--basetemp` 路径，不要把正式数据目录或个人文件目录用作测试临时目录。
